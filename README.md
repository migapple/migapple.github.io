# migapple.github.io

Page d'accueil personnelle de **Michel Garlandat**, développeur iOS indépendant basé à Paris.

## Contenu

Vitrine de 47 applications iOS publiées sur l'App Store, couvrant :

- **Histoire** — Rois de France, Présidents Français, Maréchaux Napoléon, Dynasties Russes, Dynasties Chinoises…
- **Géographie** — Capitales Europe, Pays UE, États Unis, Mers & Océans, Détroits…
- **Culture** — Comédie Française, Compositeurs, Théâtres Paris, Trains Mythiques, Avions de Légende…
- **Art & Architecture** — Ponts du Monde, Iconic Covers…
- **Jeux** — Bataille Navale, Dames Checkers, Lexigo, ColorCodeMind…
- **Utilitaires** — Frigo Manager, Cave Manager, MediSafe, MesRestaurants…

## Technique

Site statique HTML/CSS/JS — aucune dépendance, aucun framework.  
Les icônes d'applications sont chargées dynamiquement via l'API iTunes.
